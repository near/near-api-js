    Class JsonRpcProvider

    Client class to interact with the NEAR RPC API.

    Remarks

    Methods reject when an HTTP request or RPC operation fails. RPC errors are mapped to the exported classes in near-api-js/rpc-errors; transport failures can throw other error types. Convenience methods with an optional finality selector default to optimistic finality.

    • callFunction<T extends SerializedReturnValue>(

          },
      ): Promise<T | undefined>

      Calls a contract view method without submitting a transaction and decodes its result.

      Type Parameters

      • T extends SerializedReturnValue

        Expected result type. This does not validate the returned value at runtime.

      Parameters

      • params: {
            args: Uint8Array<ArrayBufferLike> | Record<string, unknown>;
            blockQuery?: BlockReference;
            contractId: string;
            method: string;
        }

        View call options.

        • args: Uint8Array<ArrayBufferLike> | Record<string, unknown>

          Arguments serialized as JSON, or a Uint8Array containing already serialized arguments.

        • OptionalblockQuery?: BlockReference

          Block height/hash or finality to query. Defaults to { finality: 'optimistic' }.

        • contractId: string

          Account ID of the contract to query.

        • method: string

          Name of the contract's view method.

      Returns Promise<T | undefined>

      The JSON-decoded result, or its UTF-8 string if it is not valid JSON. Returns undefined when the contract returns no bytes.

      Throws

      If the RPC request or contract execution fails.

      Remarks

      RPC backends may be at different heights, so a view immediately after a transaction can return older state. If you need to observe the write immediately, use bounded retries or pin the query to the relevant execution receipt's block.

      See

      Reading after a transaction
